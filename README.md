# Blog API Service 📝

A RESTful API backend built with **Django** and **Django REST Framework (DRF)** for managing blog posts, user authentication, and profile management.

## 🚀 Features

- **User Authentication:** Registration, login, and JWT/Session management.
- **Post Management:** CRUD operations for blog posts and categories.
- **API Documentation:** Interactive Swagger UI and ReDoc interface via `drf-yasg`.

## 🛠️ Tech Stack

- **Framework:** Python, Django, Django REST Framework
- **Database:** PostgreSQL
- **Tools:** Git, Swagger / OpenAPI

## ⚙️ Quick Start

```bash
# Clone repository
git clone [https://github.com/Ilhomjon-developer/blog-api.git](https://github.com/Ilhomjon-developer/blog-api.git)

# Install dependencies
pip install -r requirements.txt

# Run migrations
python manage.py migrate

# Start development server
python manage.py runserver
